# QMEC Roadmap

## Current focus

1. Profile and improve editor frame performance, including avoiding work for inactive viewports and unnecessary inspector refreshes.
2. Validate collision behavior with repeatable tests and improve solver stability for primitive and convex contacts.
3. Turn the vehicle and wheel controller scaffolding into a demonstrable drivable vehicle.

## Later milestones

1. Improve the editor workflow with physics diagnostics and more useful scene/debug visualization.
2. Expand automated math, collision, and physics regression tests.
3. Improve asset-path portability and document clean-machine setup.
4. Explore terrain generation and larger-scale performance improvements after the core demo is stable.

Keep milestones visually demonstrable and document known limitations as the engine evolves.
